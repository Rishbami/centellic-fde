"Tool use" or "function calling" for an LLM - both phrases mean roughly the same thing, different providers use different names for it. What is it, in plain terms?

- LLM as the brain, tools as the hands
- Brain generates response, hands can interact (e.g. API calls)


"AI agent" - you've probably heard the term already. What do people actually mean by it?

- Combination of LLM and tools (e.g. MCP and tools)
- Agent harnes + LLM: guides our permissions, loops, context, memory
- Capable of finding answers by itself (autonomy)
- How to resitrict/control the agent; other agents, human in the loop


Streamlit - what is it, and what's it normally used for?
- python library for building simple web interfaces
- allows us to interact as a user
- we don't need to know frontend development (no HTML, CSS, JS)
